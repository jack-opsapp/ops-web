# A clean report can still be wrong.

Prepared September 5, 2026. Held in OPS; nothing published.

## Caption

The dangerous answer is not always messy.

Sometimes it is polished, complete, and built around one detail the file never proved.

So do not make a live job the test.

Pick a closed job you know cold. Give the tool the original record. Ask for a change log with a source behind every flag and a plain list of what the file cannot prove.

Then compare the answer with what really happened.

The tool does the digging. You make the call.
